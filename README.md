# PokeBattleBar

같은 네트워크에 있는 동료와 **[PokeTokenBar](https://github.com/anthropics/poke-token-bar)
도감의 포켓몬으로** 배틀하는 macOS 앱.

토큰을 써서 키운 포켓몬이 그대로 싸웁니다. 강해지는 건 **어떤 포켓몬을 가졌는지**
뿐이고, 토큰 양은 세기에 반영되지 않습니다.

## 설치

릴리스에서 `PokeBattleBar-x.y.z-Install.command` 를 받고,
터미널에 `bash` 를 치고 **공백 한 칸** 뒤에 파일을 끌어다 놓고 엔터.

```
bash ~/Downloads/PokeBattleBar-1.11.0-Install.command
```

> 전송 과정에서 실행 권한이 벗겨지기 때문에 더블클릭하면 `permission denied` 가 납니다.
> `bash` 를 앞에 붙이면 권한과 무관하게 실행되고 Gatekeeper 경고도 나오지 않습니다.

처음이면 설치, 이미 있으면 업데이트로 알아서 진행됩니다.
앱 안에서는 **우측 상단 업데이트 버튼**으로도 받을 수 있습니다.

**필요한 것**: macOS 14+ (인텔·애플실리콘 모두), PokeTokenBar 에 포켓몬이 한 마리 이상,
첫 실행 때 인터넷.

## 배틀하는 방법

1. 메뉴바 몬스터볼 아이콘으로 창을 엽니다.
2. **로비**에 앱을 켜놓은 동료가 보입니다.
3. **방 만들기** → 대기 화면의 로비 목록에서 **초대**.
   또는 다른 사람이 방을 열면 **새 방!** 알림이 뜹니다.
4. 양쪽이 선두 포켓몬을 고르면 시작합니다.

## 다른 네트워크의 사람과 배틀 (중계 서버)

로비와 방 찾기는 **같은 네트워크**에서만 됩니다 (Bonjour 가 라우터를 넘지 못합니다).
회사와 집처럼 네트워크가 다르면 **중계 서버**를 씁니다 — 동료 중 한 명이 라즈베리파이
같은 기계에 띄워두면 됩니다.

양쪽 모두 중계기로 *나가는* 연결을 걸기 때문에, 배틀하는 두 사람은 공유기 설정이
필요 없습니다. 포트를 열어야 하는 곳은 중계기 한 대뿐입니다 (**47474/tcp**).

### 다른 회사 사람과 한다면 — Tailscale

중계기를 집이나 사무실에 두면 대개 사설 주소(`10.x`·`192.168.x`)를 받습니다.
그 주소는 그 네트워크 안에서만 통합니다. 통신사 CGNAT 뒤라면 공유기
포트포워딩조차 불가능합니다 — 그 주소를 소유한 것이 통신사이기 때문입니다.

**Tailscale 을 중계기와 참가자 전원에게 깔면** 각자 `100.x` 주소를 받고
서로 바로 붙습니다. 포트포워딩도 공인 주소도 필요 없습니다.

```bash
# 중계기(라즈베리파이)와 참가자 맥 모두에서
curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up
```

깔고 나면 중계기가 시작할 때 `100.x:47474` 를 알려줍니다. 그 주소와 암호를
동료에게 전하면 끝입니다. (맥은 App Store 의 Tailscale 앱을 써도 됩니다.)

앱의 **방 만들기** 화면도 Tailscale 주소를 알아보고 맨 위에
"다른 네트워크에서도 이 주소로 붙을 수 있습니다" 라고 표시합니다.

**중계기를 띄우는 사람** (라즈베리파이 등, 맥이 아니어도 됩니다):

```bash
# 이 저장소를 받아서
# 암호를 지정하지 않으면 자동으로 만들어 알려줍니다
bash scripts/install-relay.sh

# 직접 정하려면
bash scripts/install-relay.sh --secret 우리팀암호
```

파이썬 3 만 있으면 되고 포켓몬 앱은 필요 없습니다. 설치가 끝나면 동료에게 알려줄
주소와 **상태 화면 주소**를 출력합니다. 나중에 다시 보려면 중계기에서
`pokebattle-relay help` 를 치면 설정값이 채워진 설명서가 나옵니다. 상태 화면은 브라우저로 열어서 잘 돌고 있는지,
지금 누가 방을 열어놓고 기다리는지 볼 수 있습니다.

**배틀하는 두 사람**: 로비의 **로비 — 중계 서버** 칸에 받은 주소(와 암호)를 적고
**중계 로비 접속**을 누르면, 그 중계기에 붙어 있는 사람과 열린 방이 보입니다.
열린 방은 **참가**를 누르면 코드를 몰라도 바로 들어갑니다.
중계로 방을 열어둔 상태라면 접속자 옆의 **초대**로 부를 수도 있습니다
(로컬 로비와 같은 방식입니다 — 상대가 수락하면 바로 들어옵니다).

로비를 쓰지 않고 코드만으로 만나려면:

1. 한 명이 **중계로 방 열기** → 방 코드가 나옵니다 (예: `ABC12`)
2. 그 코드를 상대에게 알려줍니다
3. 상대가 코드를 적고 **방 코드로 참가**

로비는 두 개가 따로 보입니다 — **같은 네트워크**(Bonjour, 초대를 보낼 수 있음)와
**중계 서버**(방 코드로 들어감). 출처와 할 수 있는 일이 달라서 섞지 않았습니다.

중계기는 게임을 모릅니다 — 짝을 맞춘 뒤로는 바이트를 그대로 흘리기만 합니다.
그래서 앱을 업데이트해도 중계기는 그대로 둬도 되고, 배틀 판정은 예전처럼
방을 연 사람의 앱에서만 돌아갑니다. 다만 **중계기는 오가는 내용을 볼 수 있으니**
믿을 수 있는 사람의 기계에 띄우세요.

교체는 없습니다. 쓰러지면 다음 포켓몬을 고릅니다.
**양쪽 앱 버전이 같아야** 합니다 (프로토콜 버전이 다르면 목록에 "버전 불일치" 로 뜹니다).

## 규칙

- 6마리까지, 방에서 상한을 정합니다. **적게 가진 사람은 그만큼 불리합니다** (의도된 것)
- 실제 데미지 공식, 상성, 상태이상, 능력치 랭크, 성격 보정
- 성격은 PokeTokenBar 를 따릅니다. 노력치는 전원 0
- **메가진화 · 다이맥스 · 거다이맥스 · Z기술은 배틀당 각각 1회**, 해당 도구를 끼운
  포켓몬만. 여섯 마리가 다 거다이맥스할 수는 없습니다
- 도구 · 나무열매 · 특성을 고를 수 있고, **실전 세팅**(Smogon 분석) 중에서 골라 쓸 수도 있습니다

## 게임 모드

방 설정에서 켭니다 (겹쳐서 켤 수 있습니다).

| 모드 | 내용 |
|---|---|
| 랜덤 기술 | 배울 수 있는 기술 중 무작위 4개 |
| 자유의지 | 포켓몬이 스스로 기술을 고릅니다 |
| 자동 변신 | 도구를 끼웠다면 변신도 알아서 |
| 토게피 손가락흔들기 | 양쪽 토게피 1마리, 손가락흔들기 하나로 1대1 |

## 개발

```bash
swift build
./scripts/dev-two.sh              # 혼자 테스트 — 두 개 띄워서 서로 붙인다
./scripts/dev-two.sh 94,386 555   # 팀을 지정해서 (도감을 건드리지 않습니다)

.build/debug/PokeBattleBar --testall     # 전체 검증
.build/debug/PokeBattleBar --moveaudit   # 아직 구현하지 않은 기술 목록
.build/debug/PokeBattleBar --roster      # 내 도감 상태

# 중계 서버를 로컬에서 확인 (세 프로세스)
python3 scripts/relay.py
POKEBATTLE_RELAY=127.0.0.1 POKEBATTLE_ROOM=TEST1 .build/debug/PokeBattleBar --lanprobe relayhost
POKEBATTLE_RELAY=127.0.0.1 POKEBATTLE_ROOM=TEST1 .build/debug/PokeBattleBar --lanprobe relayguest
```

배포:

```bash
# 1) scripts/config.sh 의 REPO 를 자기 저장소로 채운다
# 2) gh auth login
./scripts/publish-release.sh 1.12.0
```
