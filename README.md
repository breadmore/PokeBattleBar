# PokeBattleBar

같은 네트워크에 있는 동료와 **[PokeTokenBar](https://github.com/anthropics/poke-token-bar)
도감의 포켓몬으로** 배틀하는 macOS 앱.

토큰을 써서 키운 포켓몬이 그대로 싸웁니다. 강해지는 건 **어떤 포켓몬을 가졌는지**
뿐이고, 토큰 양은 세기에 반영되지 않습니다.

## 설치

릴리스에서 `PokeBattleBar-x.y.z-Install.command` 를 받고,
터미널에 `bash` 를 치고 **공백 한 칸** 뒤에 파일을 끌어다 놓고 엔터.

```
bash ~/Downloads/PokeBattleBar-1.11.0-Install.command
```

> 전송 과정에서 실행 권한이 벗겨지기 때문에 더블클릭하면 `permission denied` 가 납니다.
> `bash` 를 앞에 붙이면 권한과 무관하게 실행되고 Gatekeeper 경고도 나오지 않습니다.

처음이면 설치, 이미 있으면 업데이트로 알아서 진행됩니다.
앱 안에서는 **우측 상단 업데이트 버튼**으로도 받을 수 있습니다.

**필요한 것**: macOS 14+ (인텔·애플실리콘 모두), PokeTokenBar 에 포켓몬이 한 마리 이상,
첫 실행 때 인터넷.

## 배틀하는 방법

1. 메뉴바 몬스터볼 아이콘으로 창을 엽니다.
2. **로비**에 앱을 켜놓은 동료가 보입니다.
3. **방 만들기** → 대기 화면의 로비 목록에서 **초대**.
   또는 다른 사람이 방을 열면 **새 방!** 알림이 뜹니다.
4. 양쪽이 선두 포켓몬을 고르면 시작합니다.

교체는 없습니다. 쓰러지면 다음 포켓몬을 고릅니다.
**양쪽 앱 버전이 같아야** 합니다 (프로토콜 버전이 다르면 목록에 "버전 불일치" 로 뜹니다).

## 규칙

- 6마리까지, 방에서 상한을 정합니다. **적게 가진 사람은 그만큼 불리합니다** (의도된 것)
- 실제 데미지 공식, 상성, 상태이상, 능력치 랭크, 성격 보정
- 성격은 PokeTokenBar 를 따릅니다. 노력치는 전원 0
- **메가진화 · 다이맥스 · 거다이맥스 · Z기술은 배틀당 각각 1회**, 해당 도구를 끼운
  포켓몬만. 여섯 마리가 다 거다이맥스할 수는 없습니다
- 도구 · 나무열매 · 특성을 고를 수 있고, **실전 세팅**(Smogon 분석) 중에서 골라 쓸 수도 있습니다

## 게임 모드

방 설정에서 켭니다 (겹쳐서 켤 수 있습니다).

| 모드 | 내용 |
|---|---|
| 랜덤 기술 | 배울 수 있는 기술 중 무작위 4개 |
| 자유의지 | 포켓몬이 스스로 기술을 고릅니다 |
| 자동 변신 | 도구를 끼웠다면 변신도 알아서 |
| 토게피 손가락흔들기 | 양쪽 토게피 1마리, 손가락흔들기 하나로 1대1 |

## 개발

```bash
swift build
./scripts/dev-two.sh              # 혼자 테스트 — 두 개 띄워서 서로 붙인다
./scripts/dev-two.sh 94,386 555   # 팀을 지정해서 (도감을 건드리지 않습니다)

.build/debug/PokeBattleBar --testall     # 전체 검증
.build/debug/PokeBattleBar --moveaudit   # 아직 구현하지 않은 기술 목록
.build/debug/PokeBattleBar --roster      # 내 도감 상태
```
